# Programming Mobile - Tugas 1

## Deskripsi

Project ini dibuat untuk memenuhi Tugas Pertemuan 1
mata kuliah Pengantar Pemrograman Mobile.

Aplikasi dibuat menggunakan MIT App Inventor
dengan memanfaatkan komponen WebViewer.

## Fitur

- Menampilkan website berita teknologi
- Tombol Home
- Tombol Refresh

## Teknologi

- MIT App Inventor
- WebViewer
